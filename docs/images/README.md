# Documentation images

| File | Source | Purpose |
|------|--------|---------|
| `winamp-main.png` | Project classic skin `assets/MAIN.BMP`, nearest-neighbor scaled 3× | README hero (main window chrome) |
| `winamp-classic-stack.png` | Project classic skin bitmaps (`MAIN.BMP`, `Eqmain.bmp`) + illustrative playlist panel | Full stack illustration |

These assets ship with the repository so the README renders offline on GitHub without hotlinking third-party hosts. They reproduce the classic Winamp 2.x *visual language* used by this player’s default skin in 1.3.1. They are illustrations of that chrome, not screenshots of the terminal UI or of the AppImage.
