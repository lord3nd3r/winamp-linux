## 🔴 CRITICAL FINDINGS

### 1. Zero Exception Handling
- **Status**: No try/catch blocks in entire codebase
- **Risk**: Python plugins, Qt multimedia, file I/O, network operations will crash app on exception
- **Action Required**: Wrap all external boundaries (plugin calls, network, file ops, XML parsing)

### 2. Monolithic Architecture (5205-line main.cpp)
- **File**: src/main.cpp
- **Contains**: 6 classes, FFT impl, network handling, plugin orchestration, UI rendering, file I/O
- **Problem**: Untestable, high coupling, merge conflicts
- **Refactor Target**: Split into audio_engine, ui_manager, plugin_manager, network_handler modules

### 3. No Test Infrastructure
- **CMakeLists.txt**: No test framework, no test target
- **Critical untested paths**:
  - EQ DSP algorithm (src/eq_dsp.h) — audio quality regressions undetectable
  - Async playlist loading (src/playlist.h) — timeout/hang scenarios
  - XML skin parsing (src/modern_skin.h) — malformed input, XXE attacks
  - Python plugin system (src/python_plugin.h) — crash/exception scenarios
- **Action**: Add Qt Test or Catch2 framework

### 4. Python Plugin Security — No Sandboxing
- **File**: src/python_plugin.h
- **Issue**: Plugins have unrestricted access via friend class
- **Attack Surface**: Malicious plugin can crash app, access filesystem, execute arbitrary code
- **No resource limits**: Memory, CPU, file handles
- **Action**: Consider subprocess isolation or resource quotas

### 5. Manual Memory Management (53 instances)
- **Location**: src/main.cpp (53 new/delete/malloc/free calls)
- **Risk**: Leaks, use-after-free, double-free
- **Qt Pattern Violation**: Should use parent-child ownership, not manual new
- **Action**: Audit all 53 instances, convert to Qt ownership or std::unique_ptr

## ⚠️ HIGH-PRIORITY ISSUES

### 6. Network Security — HTTP Stream Handling
- **Files**: src/main.cpp:3151-3153, src/compat.h, src/constants.h:64-67
- **Issues**:
  - No redirect limit (infinite redirect vulnerability)
  - Permissive URL validation (QUrl::fromUserInput)
  - Supports http, https, icy, ftp
  - Missing: timeout enforcement, max response size, redirect depth limit
- **Action**: Add redirect counter (max 5), response size limit, strict validation

### 7. XML Parsing — Billion Laughs Vulnerability
- **File**: src/modern_skin.h
- **Issue**: Recursive `<include>` with no depth limit
- **Attack**: Malicious skin can cause infinite loop, memory exhaustion, DoS
- **Action**: Add include depth counter (max 10 levels)

### 8. Header-Only Architecture
- **Pattern**: All .h files contain full implementations
- **Problems**: Compilation coupling, hidden dependencies, bloated compile times
- **Recommendation**: Refactor to .h/.cpp separation (long-term)

### 9. Build System Gaps (CMakeLists.txt)
- **Missing**:
  - Warning flags (-Wall -Wextra -Werror)
  - Hardening flags (-fstack-protector, -D_FORTIFY_SOURCE=2)
  - Sanitizer support (ASan, UBSan, TSan)
  - Language pack install (lang/*.lang)
  - Package metadata
- **Action**: Add compiler flags immediately

### 10. Error Handling Patterns
- **Style**: Qt signals, bool returns, no exceptions
- **Missing defensive checks**:
  - Null pointer checks before dereference
  - File existence before open
  - Division by zero in DSP/FFT
  - Array bounds checking
- **Action**: Add null guards at external boundaries
